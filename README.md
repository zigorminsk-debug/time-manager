# Тайм-менеджер с голосом и напоминаниями по месту

Android-приложение на Kotlin + Jetpack Compose: задачи с точными напоминаниями,
голосовым вводом, проговариванием дня, чекбоксами, архивом и напоминаниями
по прибытии в место (GPS + Wi-Fi). Собирается и подписывается автоматически
в GitHub Actions, обновляется «поверх» установленной версии.

## Возможности

### Задачи
- Создание задачи текстом **или голосом** (системное распознавание речи, ru-RU).
- **Дата и время в календаре** — стандартный выпадающий `DatePicker` + `TimePicker`.
- **Дата и время голосом**: «завтра в три часа дня», «в пятницу в 18:30», «через 2 часа»,
  «3 ноября в 12:00», «25.12 в 10:00», «в понедельник», «в 7 вечера», «послезавтра в полдень».
  Распознанная дата вырезается из названия задачи и подставляется в поля.
- Понимает и текст: если напечатать «позвонить маме в 15:30», приложение предложит
  применить найденное время одним тапом.
- **Предупреждение о наложении**: если задача пересекается по времени с другой
  (окно ±30 минут), показывается предупреждение — до сохранения и значком на карточке.
- **Отложить** на 10 / 15 / 20 / 30 минут (кнопка в уведомлении, в баннере и в меню задачи).
- **Перенести** на другой день/время: быстрые варианты («через час», «сегодня вечером»,
  «завтра утром») или календарь.
- Повторы: каждый день, по будням, каждую неделю, каждый месяц.
- Чекбокс выполнения → задача уходит **в архив** и исчезает из текущих;
  из архива можно вернуть или удалить.

### Напоминания
- Точные будильники (`AlarmManager.setExactAndAllowWhileIdle`) с корректной работой
  в Doze; при отсутствии разрешения — аккуратный fallback.
- Уведомление-будильник с кнопками **Выполнено / 10 мин / 30 мин / Отложить…**,
  полноэкранное напоминание поверх блокировки для важных задач.
- Кнопка «Отложить» открывает выбор 10/15/20/30 минут.
- Периодическая «страховка» раз в 15 минут: просроченные задачи, места, обновления.

### Места (напоминание при прибытии)
- В форме места показывается список **Wi-Fi сетей, которые вещают прямо здесь**: подключённая,
  сохранённые на телефоне и просто видимые, с уровнем сигнала и пометками
  «подключена» / «сохранена» / «защищена». Достаточно отметить нужные галочкой;
  сеть можно вписать и вручную (например, если она сейчас не в зоне).
- Срабатывание — по **зоне вещания** выбранной сети (телефону не нужно к ней подключаться),
  а также по GPS-координатам и радиусу.
- Сравнение сетей: SSID без учёта регистра и кавычек, MAC-адреса — в любом формате;
  «Home» не сработает на соседнюю «Home_Neighbor».
- Фоновый foreground-сервис слушает GPS и раз в минуту проверяет Wi-Fi.
- При совпадении — **постоянный баннер**, который висит, пока задачу не выполнят
  или не отложат; повторно не «звенит».
- Сравнение Wi-Fi нечувствительно к регистру и кавычкам, работает даже без GPS
  (например, дома телефон цепляется за домашнюю сеть).

### Интерфейс и адаптивность
- Единая сетка размеров: все основные кнопки — 52 dp высотой и с одним радиусом,
  вторичные — 44 dp, иконки-кнопки — ровно 48×48 dp, чипы — одной высоты.
  Кнопки в рядах делят ширину поровну, поэтому не «разъезжаются» на разных экранах.
- Быстрый выбор времени — сетка с равными кнопками: 2 колонки на узком экране, 3 на широком.
- На планшетах и в ландшафте контент центрируется и не растягивается шире 640 dp.
- Нижнее меню: на узких телефонах подпись показывается только у выбранного пункта.
- Выбор времени: на узких экранах — компактный `TimeInput` вместо широкого циферблата.
- Метаданные задачи (дата, место, отсрочка, пересечение) переносятся на новую строку.
- Форма задачи — полноэкранный диалог с закреплённой кнопкой сохранения (не перекрывается клавиатурой).

### Голос
- **«Проговорить день»** — TTS читает задачи на сегодня с временем и местами,
  включая просроченные; кнопка «Остановить».
- Проговаривание напоминаний при срабатывании (можно отключить).
- Скорость речи настраивается.

### Обновления
- Проверка новых версий по GitHub Releases (канал «стабильные»/«бета»).
- Автоскачивание APK, проверка `sha256`, передача системному установщику.
- APK подписан **постоянным ключом** из репозитория → обновление ставится поверх,
  данные и настройки сохраняются.

## Установка

1. Скачайте APK из [Releases](https://github.com/zigorminsk-debug/time-manager/releases).
2. Разрешите установку из этого источника и установите.
3. При первом запуске выдайте разрешения: уведомления, местоположение
   (для напоминаний по месту — «Всегда»), точные будильники.
4. На Xiaomi/Huawei дополнительно разрешите автозапуск и снимите оптимизацию батареи
   (Настройки → Энергосбережение).

## Сборка

Локально нужен JDK 17 и Android SDK 34:

```bash
./gradlew :app:assembleRelease -PappVersionCode=1005 -PappVersionName=1.0.5
# APK: app/build/outputs/apk/release/app-release.apk
```

Тесты (разбор русских дат и времени):

```bash
./gradlew :app:testDebugUnitTest
```

CI: каждый push собирает APK, прогоняет тесты и (для ветки `main`) публикует
релиз с `versionCode` и `sha256` в описании — из этих данных приложение узнаёт
о новой версии.

## Подпись и обновления

| Что | Значение |
|---|---|
| Keystore | `keystore/timemanager-release.p12` (PKCS12) |
| Alias | `timemanager` |
| Пароль хранилища и ключа | `timemanager` |
| Срок действия сертификата | 30 лет |

Ключ лежит в репозитории, чтобы любая сборка (в том числе в CI) подписывалась
одним и тем же сертификатом — иначе Android не установит обновление поверх.
Переопределить можно переменными окружения: `TM_KEYSTORE_FILE`,
`TM_KEYSTORE_PASSWORD`, `TM_KEY_ALIAS`, `TM_KEY_PASSWORD`, `TM_KEYSTORE_TYPE`.
P12-файл намеренно **не** добавлен в `.gitignore`.

Установка APK всё равно требует подтверждения пользователя (ограничение Android
для обычных приложений), поэтому «полностью беззвучного» автообновления быть не может:
приложение само скачивает новую версию и предлагает одно нажатие «Установить».
На устройствах с root/device owner установка может проходить совсем без участия человека.

## Архитектура

```
app/src/main/java/com/zigorminsk/timemanager/
├── TimeManagerApp.kt        граф зависимостей, восстановление будильников при старте
├── data/Store.kt            JSON-хранилище задач/мест + настройки (StateFlow)
├── model/Model.kt           Task, Place, AppData, Settings, RepeatRule
├── util/TimeText.kt         RuTime (форматирование, TTS) + RuTimeParser (разбор речи)
├── util/Conflicts.kt        поиск пересечений по времени
├── notify/AlarmScheduler.kt точные будильники, heartbeat, PendingIntent-ы
├── notify/ReminderEngine.kt срабатывание, «выполнено», отсрочка, проверки
├── notify/Notifications.kt  каналы, баннеры, кнопки действий
├── notify/*Receiver.kt      будильники, кнопки уведомлений, загрузка ОС
├── place/PlaceMonitor.kt    определение «я на месте» по Wi-Fi и GPS
├── place/PlaceWatchService.kt foreground-сервис слежения
├── speech/Speech.kt         распознавание речи и Text-to-Speech
├── update/UpdateManager.kt  GitHub Releases, скачивание, установка (WorkManager)
└── ui/                      Compose: Сегодня, Все, Архив, Места, Настройки, будильник
```

Данные хранятся только на устройстве: `filesDir/timemanager.json` и SharedPreferences.
Экспорт задач — в настройках (JSON через «Поделиться»).

## Если что-то пошло не так

Приложение пишет отчёты о сбоях: при следующем запуске показывается диалог с текстом
ошибки (кнопки «Копировать» и «Отправить»). То же самое доступно в
«Настройки → Диагностика → Последняя ошибка». Отчёт содержит версию, модель устройства
и стек вызовов — этого достаточно, чтобы воспроизвести и исправить проблему.

## Ограничения

- Распознавание речи использует системную службу (обычно Google) — интернет нужен,
  язык должен поддерживаться; на устройствах без неё доступен только текстовый ввод.
- «Всегда разрешать» геолокацию и отключение энергосбережения на некоторых прошивках
  выдаются только вручную в настройках Android.
- Точность определения прибытия зависит от Wi-Fi/GPS; радиус по умолчанию 200 м.
- Проверка обновлений идёт по публичному GitHub API (лимит 60 запросов в час на IP).
